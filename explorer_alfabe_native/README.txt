WINDOWS 11 EXPLORER ALFABE ÇUBUĞU v2.0.0

Bu sürüm yalnız orijinal Windows 11 Dosya Gezgini içindir.

- Görünüm düğmesinin yanına A-Z düğmesi ekler.
- Windows 11 ile uyumlu yuvarlatılmış alfabe paneli açar.
- Türkçe harfleri destekler.
- Aynı harfe yeniden basınca sonraki eşleşmeye geçer.
- Büyük pencerede 2, küçük pencerede 3 satır gösterir.
- Windows ile sessizce başlar.
