# Files Alfabe

Files 4.0.38 tabanlı kişisel Windows dosya yöneticisi sürümü.

- Araç çubuğunda A-Z alfabe düğmesi
- Türkçe harf desteği
- Aynı harfe tekrar basınca sıradaki eşleşmeye geçiş
- Başlat menüsünde **Files Alfabe** adı

Kurulum paketi GitHub Actions bölümündeki en güncel **Files-Alfabe-x64** çıktısındadır.
